# CS2C · 硬件级 CS2 全功能辅助系统

> **FPGA · 纯本地处理 · 无侵入 · 无修改**

面向 Counter-Strike 2 的**硬件级外部辅助系统**，使用 C++ 开发。DMA 设备（FPGA 开发板）插在**主机（运行游戏的电脑）**上，仅对开发板上已有的模拟内存数据做快速读取与再处理；**全部运算在副机（运行本软件的电脑）本地完成**，鼠标指令经 **KMBox / MAKCU 等硬件盒子**下发到主机 —— 主机上不装驱动、不跑软件。

> 本软件不能用于实际计算机系统，仅作用于 FPGA 开发板中已有的模拟内存数据的快速读取和再处理，无任何对计算机系统或其它安全功能的侵入控制及修改操作。仅供学习与研究用途；因不当使用产生的后果由用户自行承担。

## 架构与硬件链路

```
[主机 · 游戏机]  运行 CS2 游戏 + DMA 卡（FPGA 开发板，插在主机）
      ▲                        │
      │ 硬件盒子下发鼠标         │ USB 读取数据
      │                        ▼
[副机 · 控制机]  FPGA 开发板 USB 接副机 → 本地完成全部运算 → 渲染黑底 ESP 画面
      │
      │ 融合器「去黑」叠加 ESP
      ▼
[主机 · 游戏机屏幕]  游戏画面 + ESP 框线
```

- **主机 = 游戏机**：跑游戏本体、插 DMA 卡，**不安装任何软件/驱动**。
- **副机 = 控制机**：通过 USB 连接 DMA 卡，运行 `CS2C.exe` / `CS2DMA.exe`，本地完成全部运算。
- **鼠标下发**：自瞄/压枪算出的准星位移，经 **KMBox / MAKCU 等硬件盒子**下发到主机，等效真实鼠标移动，**不会写游戏内存**。
- **画面叠加**：副机渲染黑底 ESP → 融合器「去黑」抠掉黑底 → 叠加到主机屏幕。

### 偏移过期怎么办？

CS2 每次更新后偏移可能失效，表现为 ESP 不显示或数据异常。三种保障：

1. **偏移云同步** - 数据正常时自动上传新偏移；更新后在设置页一键从云端拉取
2. **本地提取** - 程序检测到游戏更新时，调用内置提取工具本地重新提取偏移
3. **手动** - 从 [cs2-dumper](https://github.com/a2x/cs2-dumper) 获取最新偏移文件替换软件目录下的偏移文件
